## 1. 定位与边界

P1-B 的目标是**脚本化 2D 草图**的最小闭环，不是 D-Cubed 级商用求解器。

明确不做（YAGNI）：

- 符号图分解 / 尺规作图闭式约简（前沿法、刚体团分解）——留到有真实性能压力后再评估；
- 多解同伦追踪与全局分支枚举；
- 3D 装配约束、机构运动学。

允许的两条实现路线（二选一，ADR 级裁决）：

| 路线 | 做法 | 适用 |
|:--|:--|:--|
| **B-1 最小闭包** | 固定初值的局部 Levenberg–Marquardt + Jacobian SVD 秩/零空间分析 | 单草图、变量数 ≤ 几十 |
| **B-2 FFI 封装** | 包 `libslvs`（SolveSpace）或等价库，只做接口与重放层 | 需要成熟求解质量时 |

无论哪条路线，**验收判据在本规范**，不在实现细节。

## 2. 约束模型（最小集）

- 图元：点、直线段、圆弧（圆心/半径/起止角）；
- 约束：重合、水平、垂直、平行、距离、半径、相切（线-圆、圆-圆）、同心；
- 每个约束带稳定 `id`，与 `EntityRef` 引用一一对应；
- 欠约束/过约束/矛盾必须能被诊断，不允许静默返回"最接近的解"。

## 3. 验收线（硬性）

### 3.1 残差

- 构造即满足的配置：残差 = 0（机器精度内，报告 `< 1e-12`）；
- 一般配置：收敛后 `max |residual| < 1e-10`（相对特征尺寸归一化）。

### 3.2 分支连续性 / 手性（Chirality）—— 仅测残差抓不住的核心

相切、距离约束是二次方程，存在多组合法解。尺寸连续微调时，求解器不得跳到镜像解。

测试协议（必须进 conformance 或 pytest）：

1. 构造一个多解草图（例如两圆相切 + 圆心距约束），记录初始分支；
2. 让驱动尺寸从 `d0` 连续扫到 `d1`（如 20 → 20.5），小步长、多次重解；
3. 每一步以上一步解为初值，要求：
   - 残差达标；
   - **分支不翻转**：圆在直线的同一侧、相切类型（内切/外切）不变；
   - 若翻转不可避免（解合并/分岔），必须显式报 `DomainError` 或返回带 `branch_changed` 标记的结果，**不得静默换分支**。

### 3.3 自由度与冲突诊断

- DOF 分类：矩形 = 4、三角形 = 3、欠约束/过约束构造，分类 100% 正确；
- 矛盾约束：必须指出**最小冲突集**（至少给出约束 id 列表），不允许只报"矩阵奇异"；
- 冗余约束：可接受（不报错），但要在诊断中标出；
- 奇异/不一致：`DomainError`，不返回近似解。

### 3.4 引用与重放

- 草图实体走 `EntityRef`；每条约束的引用必须可解析；
- 同一 `sketch.json` 重放两遍，id 序列与约束图一致；
- 参数化修改（尺寸变化）后的引用稳定性：**本阶段不承诺 TNP**（ADR-0004），只保证同一脚本重放。

## 4. 与验证台的关系

- 求解器核心（Jacobian、LM、SVD）是纯数值叶子，可用构造解 + 有限差分对拍；
- "分支不翻转"与"最小冲突集"属于**过程性证据**，应放 conformance 的脚本用例或 pytest 的序列测试，而不是单点残差断言；
- 变异自审至少覆盖：残差符号、Jacobian 装配、SVD 秩判定、分支选择条件。

## 5. 未决问题（HITL）

1. 相切约束的容差语义：几何相切（点到圆心距离 = r）还是数值最近（允许残差带）？
2. 返回多解时是否允许 `solutions: list`，还是只返回一条并拒绝歧义？
3. 欠约束草图的"最小范数解"是否可作为默认？工业界通常给用户自由拖动，不自动补约束。
